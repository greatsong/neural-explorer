# 특강 「손으로 풀어보는 딥러닝의 원리」 — 사용자 지시 사항 정리 (외부 검증용)

작성일: 2026-09-17. 이 문서는 사용자(교사)가 이 특강 자료를 만들며 내린 지시와 결정을 빠짐없이 모은 것이다. 다른 AI가 산출물을 검증할 때 "무엇을 요구받았는가"의 기준으로 쓴다. 지시 원문은 가능한 한 그대로 옮겼고, 작업자(Claude, 팀장)가 제안해 사용자가 진행을 승인한 사항은 따로 표시했다.

## 3. 작업자(Claude)의 제안과 사용자의 승인

작업자가 아래를 제안했고, 사용자가 "네 활동지와 교재가 필요해요"라고 답해 이 제안대로 산출물 제작을 진행했다. 검증자는 아래 항목이 산출물에 실제로 반영되었는지, 그리고 반영이 사용자의 원 구성안 취지를 해치지 않는지 본다.

| # | 제안 | 원 구성안과의 차이 |
|---|---|---|
| A | 오차·MSE(세션3)를 경사하강법 설명 **앞**에 둔다 | 원안은 경사하강법 → 오차 순서. 손실이 정의되기 전에는 경사하강법을 설명할 대상이 없다는 이유 |
| B | "계산식 유도"는 기호 미분이 아니라 **양옆 손실 차이(수치)** 로 한다. 손실 L = (w − 5)²에서 (오른쪽 − 왼쪽) ÷ 2를 계산하면 2(w − 5)와 정확히 일치함을 학생이 발견. dw = 평균(e·x), db = 평균(e)는 결과로 주고 "책임 분담" 직관과 표 계산으로 확인. 미분을 아는 학생용 사슬규칙 유도는 교재의 별도 상자 | 중2는 미분 미학습. 과학고 지망생이라도 전원 선행은 아님 |
| C | 100분 중 48~53분에 **5분 휴식**, 마지막 5분 예비 | 원안에 휴식 없음 |
| D | 3B 질문을 세션1 끝(파라미터 세기)과 마무리에서 **두 번 회수**. 뉴런 하나 3개 → 3×2×1 신경망 11개 → 손글씨 784-16-10 신경망 12,730개 → 3B = 30억 개 | 원안의 "파라미터 숫자 계산" 취지를 구체화 |
| E | 계보 스토리를 뒤의 실습이 풀어 줄 **갈등 두 개**를 심는 구조로. ① 1958 로젠블랫 "틀리면 가중치를 어떻게 고치나" → 세션3·4가 답. ② 1969 민스키 "직선 하나뿐" → 활성화 함수 실습(2-3)과 플레이그라운드가 답 | 원안의 "재미있는 스토리"를 복선 구조로 구체화 |
| F | 플레이그라운드는 **활성화 함수 직후**(세션2와 3 사이)에 교사 시연 3장면(은닉층 없음 / Linear / ReLU), **마무리**에 손실 곡선 1분. 학생 개별 조작은 하지 않음(영어 UI). 한 step 손계산 후 자동 반복은 자체 앱 A5로 | 원안의 "어딘가에 플레이그라운드" 위치 확정 |
| G | 세션4-B는 w = 0, b = 0에서 출발(ŷ이 전부 0이라 표가 쉬움), η = 0.05, 한 step 뒤 점 (3, 7)의 손실 49 → 8.41 확인이 특강의 절정 | 기존 A부 활동지 A4-2·A5-2·A5-3과 같은 수치 |
| H | 시간이 밀릴 때 첫 절약 후보는 세션3의 다섯 점 MSE 표를 세션4-B 표의 e 열로 합치는 것 | — |

## 4. 제작 중 추가된 사용자 지시 (시간 순)

1. **"네 활동지와 교재가 필요해요."** → 산출물 두 종류: 학생 활동지, 학생 교재. 작업자가 교사용 정답·진행안을 추가로 만들었다.
2. **"용어를 우리 수업 수준으로 써도 됩니다."** → 기존 Neural Explorer 교재(고등학생 대상) 수준의 용어(손실, MSE, 학습률 η, 파라미터, 경사하강법, 역전파 등)를 그대로 써도 된다. 작업자가 처음 제안했던 "이 특강 안에서 계산해 본 것만 이름을 붙인다"는 엄격한 용어 필터는 적용하지 않는다. 다만 본문 흐름에서 미분 기호(∂, 사슬규칙)는 빼고 별도 상자에만 둔다는 방침은 유지했다.
3. **"활동지는 친절하면서 빈 칸을 잘 넣어야 합니다."** → 활동지 어투를 "~하세요/~합니다"로 하고, 문항마다 "이렇게 하세요" 안내 상자를 두었다. 모든 표에 회색 **시범** 칸(첫 행 또는 첫 열)을 채워 두고 나머지를 빈칸으로 두었다. 빈칸은 최종 답만이 아니라 중간 단계(예: ReLU(  ) = , 0 − 0.05 × (  ) = 0 +  = )에도 두었다.
4. **"다른 AI에게 검증 받으려고 하니까, 제가 지시한 내용 모두 잘 정리해주세요."** → 이 문서.
5. **"우리가 만든 인터랙티브 교재를 잘 쓰는 방안도 함께 고려 중인가요? 아니면 특강용으로 기존 웹 교재를 커스터마이징해도 됩니다."** → 현재 자료는 앱을 교사 시연 3지점(A3 포물선·η 칩, A5 자동 step, C2 파라미터 수 표시)에서 쓴다. 앱 커스터마이징(특강 모드)은 작업자가 방안을 제시하고 사용자 결정을 기다리는 상태다(아래 8절).
6. **"-니다 체로 써주세요."** → 교재 본문을 해요체에서 합쇼체(~합니다)로 다시 집필했다. 활동지 안내문과 교사용 멘트도 합쇼체. 교사용 진행 메모의 표 안 서술은 기존 교사용 활동지 관례대로 한다체.
7. **"파라미터 숫자는 신경망 구조를 보여주고 계산하라고 해야죠."** → 1-4를 공식 제시형에서 **그림 제시형**으로 바꿨다. 3 × 2 × 1 신경망은 선 8개를 모두 그린 그림, 784-16-10은 일부만 그린 개략도를 놓고, 학생이 "선의 개수(가중치) + 입력을 뺀 뉴런의 개수(편향)"를 직접 센다. "선의 개수 = 앞층 × 뒤층"은 세고 난 뒤의 정리로만 준다. 세션2의 2-2는 같은 그림에 가중치·편향 값을 얹어 그림에서 값을 읽어 순전파를 계산한다.
8. **"전체적으로 고민을 좀 하세요. 그동안 우리 교재의 고민을 더 업그레이드 시켜야 하는데 이렇게 대충하면 어떻게 하나요."** → 작업자가 스스로 찾은 결함을 함께 고쳤다. ① 교재 본문에서 굵은 글씨 태그를 강제한 탓에 솔라가 문단 끝에 "이 값을 오차라고 합니다" 같은 군더더기 문장을 붙이던 것을 제거(태그 강제를 없애고 첫 등장 용어만 조립 단계에서 기계적으로 굵게). ② 2-3의 모눈 범위가 −3까지라 계산값 −4가 밖으로 나가던 것을 −4~4로 수정. ③ 기존 교재 A3의 학습률 네 시나리오(발산·진동·수렴·느림)를 손계산으로 옮긴 4A-4 추가(η = 0.01 / 0.1 / 0.5 / 1.2, 같은 자리에서 한 걸음). ④ 2-3에 "ReLU 없음 줄을 식으로 정리하면 ŷ = 2x − 4, 여전히 일차함수" 한 줄 추가(활성화 함수 없이는 층을 쌓아도 직선이라는 것의 손계산 증명).

9. **"해설지는요?"** → 교사용 문서를 HWPX로 변환해 드라이브에 올렸다(`print/special-ms2-teacher.hwpx`).
10. **"지금 이 hwpx는 뉴럴 익스플로러 웹앱과 정확히 연동되나요?"** → 앱 소스와 대조했다. A1 기본값, A5 데이터·학습률·첫 step 기울기(dw −25, db −7)·갱신 결과(w 1.25, b 0.35)는 일치했다. 어긋난 세 곳을 찾았다: ① 앱 A3·A5는 손실에 ½을 곱해 표시해 활동지 숫자의 절반이었다 ② 활동지 4-A의 (w − 5)²는 앱 A3 곡선과 다른 문제였다 ③ 앱 C2 은닉층 기본값이 4라 파라미터가 3,190으로 표시된다.
11. **"앱을 기반으로 설명할 때 활동지로 수업할 수 있어야 합니다."** → 활동지를 앱과 같은 문제로 다시 짰다. 세션 4-A를 앱 A3의 b 모드(w = 2 고정, b만 이동, 출발 b = −2)와 같은 문제로 바꿨다. 다섯 점의 오차가 모두 b − 1로 같아져 손실이 L = ½(b − 1)² 한 줄이 된다. 보폭 네 가지는 앱 칩 값(0.05 · 0.5 · 2.0 · 2.5)과 같다. 세션 4-B의 손실도 앱 A5가 표시하는 ½ 형태(28.5 → 4.77)로 맞췄다. 세션 3은 앱 A2와 같은 MSE를 그대로 쓴다.
12. **"활동지 앱 모두 수정해도 되니 살펴봐주세요."** → 앱은 고치지 않기로 판단했다. 앱의 ½ 손실 규약은 기존 A부 교재·활동지 전체가 따르고 있어 앱을 바꾸면 고등학교용 자료가 모두 어긋난다. 대신 앱 A3를 b 모드로, C2를 은닉층 16으로 두라는 준비 절차를 해설지에 넣었다.
13. **"교육적으로 문제가 있거나 개선하면 좋겠다고 생각하는 부분이 있으면 제안해 주세요."** → ½을 근거 없이 주던 방식을 바꿔, 4A-3에서 ½ 없이 구한 기울기(2배)와 나란히 비교해 학생이 이유를 직접 확인하게 했다.
14. **교육 목적 재확인**: 딥러닝의 핵심 원리를 손으로 직접 계산하며 배운다. 대상은 수학·과학에 관심 있는 중2이며, 어려운 수학은 피하되 충분히 이해할 수 있다는 전제로 차근차근 쉽게 만든다.
15. **"수업으로 진행한다면 몇 분 정도가 적당할지 현실적으로 판단해서 보고해 주세요."** → 손으로 채우는 칸 205개, 문항 23개 기준으로 130~160분이 걸린다고 보고했다. 해설지에 120분 연강과 100분 축소판 두 편성을 나란히 넣었다. 사용자는 상황에 따라 직접 고른다.
16. **1-4와 4B-1 개선 반영 지시.** 1-4는 784 × 16 같은 큰 곱셈의 결과를 제시하고, 학생은 어떤 두 수를 곱하는지만 찾는다. 4B-1은 앱 A1 처음 상태에서 w₁과 w₂를 각각 1에서 1.5로 올려 z 변화(1과 1.5)를 손으로 계산하고 화면과 대조한 뒤, 4B 데이터에서 w를 0.1 올릴 때 x = 5인 점이 x = 1인 점보다 5배 움직이는 것을 확인한다.

17. **"다른 에이전트를 불러서 교육적 효과와 의미를 평가해주세요."** → 수업 설계 전문가(Opus)와 중2 학생 역할(Sonnet) 두 에이전트가 독립 평가했다. 작업자가 지적을 원문과 대조해 오류 4건(역사 서술, 문항 참조, "100분" 머리말, 4B-5 전체 손실 경로)과 설계 개선 5건을 확인했다.
18. **"모두 다 타당해요. 다만 시간은 제가 판단할게요. 이번엔 오퍼스 5.5로 써주세요."** → 시간 편성은 건드리지 않았다. 이번 교재 문단은 솔라 대신 Opus 5.5가 직접 썼다. 반영 내용: 역사 서술 정정(1958 퍼셉트론은 이미 "오차 × 입력" 수정 규칙이 있었고, 남은 문제는 여러 층 학습이었으며 1986 역전파가 풀었다. 당시 활성화 함수는 ReLU가 아니었다), 4B-1에 4-A와 잇는 확인 문항 추가(점 (3, 7)에서 양옆 차이 −21 = e × x, −7 = e × 1), 4A-3에 ÷ 2의 근거(두 점을 이은 직선의 기울기), 교재 5절에서 "기울기"의 두 뜻 구분, 4A-1에 일반 행과 MSE → ½ × MSE 사슬 추가, 발견 내용을 미리 말하던 제목·문장 수정(4A-1, 2-3, 3-1), 2-2 그림을 실선(h₁)과 점선(h₂)으로 구분, 4A-2에 함수 표기 안내, 4-B에 ReLU 생략 이유, 4B-5에 1958 연결 문항, 참조 오류 수정, 해설지에 예상 질문 2개.

## 5. 적용 중인 상위 규칙 (사용자의 전역 설정, 이 세션 이전에 확정)

- 한글 산문은 솔라 프로4(Upstage)가 설계서(브리프)를 받아 집필하고, Claude는 사실·수치·태그·의미 보존만 검증해 조립한다. 문체 취향으로 고치지 않는다. 교재의 문단 22개가 이 방식으로 만들어졌다(합쇼체 재집필 포함 세 차례 호출). Claude가 조립 단계에서 한 기계적 처리는 하나뿐이다: 용어 13개(가중치·편향·활성화 함수·파라미터·순전파·ReLU·오차·손실·MSE·기울기·학습률·경사하강법·step)의 본문 첫 등장에 `<b>` 태그를 씌웠다. 문장은 바꾸지 않았다.
- 한글 문장 원칙: 대시(—) 연결 금지, 은유·의인화 기본 삭제, 구어체("그냥", "~겠지요") 금지, 완곡 표현("~하는 셈입니다") 금지, "견주다" 등 문어투 금지, 종결 어미 통일.
- 활동지 표·수식·수치·그림은 Claude 담당(솔라 집필 대상에서 제외).
- 학습 자료에서 미배운 용어는 언급하지 않는 것이 기본(이번 특강은 위 4-2 지시로 완화).
