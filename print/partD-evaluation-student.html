회귀 평가(잔차·MAE·RMSE·R²) + 분류 평가(정확도·정밀도·재현율·F1·임계값)를 작은 표로 직접 계산합니다
앱 페이즈 D1·D2 · 대상: C까지 학습한 고등학생 · 활동 시간 60~80분
한 모델이 "잘 맞췄는지"를 한 숫자로 말하기 위해 회귀에서는 네 지표, 분류에서는 다섯 숫자(혼동행렬 + 네 지표)와 임계값을 사용합니다. 이 활동지에서는 모든 지표를 작은 표로 직접 계산하고, 시나리오에 따라 좋은 모델이 어떻게 달라지는지 직접 골라 봅니다.

섹션 1. 회귀 평가 — 잔차에서 R²까지

1-B MAE 계산
|잔차|의 합을 표본 수 N으로 나누면 평균 절대 오차(MAE)입니다.
MAE = ( |잔차₁| + |잔차₂| + … + |잔차ₙ| ) / N
MAE = / 5 = °C
읽는 법
"평균적으로 °C 정도 빗나간다"고 말할 수 있어요. 단위가 원본과 같은 °C라는 것이 장점.
1-C MSE · RMSE 계산
잔차의 제곱 합을 N으로 나누면 MSE, 거기에 루트를 씌우면 단위가 다시 °C로 돌아오는 RMSE입니다.
MSE = ( 잔차₁² + 잔차₂² + … + 잔차ₙ² ) / N = / 5 = °C²
RMSE = √MSE = √ = °C
