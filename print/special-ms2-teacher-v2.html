0. 학습 목표

  1. 딥러닝 그림을 보고 은닉층(히든 레이어)이 몇 층인지, 인공 뉴런과 파라미터가 몇 개인지 셀 수 있다. "3B 모델"의 뜻을 파라미터 수로 설명할 수 있다. (세션1, 특히 1-4·1-5)
  2. 인공 뉴런과 작은 신경망의 계산(순전파)을 손으로 하고, 활성화 함수가 필요한 이유를 설명할 수 있다. (세션2)
  3. 오차와 손실을 계산하고, 오차를 제곱하는 이유를 설명할 수 있다. (세션3)
  4. 기울기를 구해 파라미터를 한 step 고치고, 손실이 줄어드는 것을 확인할 수 있다. (세션4)

3. 활동지 정답과 진행 메모

세션 1

1-1가중치만 있을 때
정답(1, 1) → 5 · (2, −1) → 1 · (−1, 3) → 7. (앱 A1 기본값 x₁ = 2, x₂ = 3, w₁ = w₂ = 1, b = 0에서 z = 5가 화면에 표시되므로 둘째 줄은 앱으로 검산 가능.) 관찰: 작아졌습니다 / 줄이는.
1-2편향이 더해지면
정답b = +3 → 8 · b = −7 → −2. b가 하는 일: 입력과 상관없이 기본 점수를 올리거나 내린다.
1-3활성화 함수(ReLU) 통과시키기
정답−1 → 0 · 0 → 0 · 2.5 → 2.5 · 7 → 7. 1-2의 z = −2 → ŷ = 0.
1-4파라미터 세기
정답3 × 2 × 1: 선 = 입력→은닉 6, 은닉→출력 2, 합 8 · 뉴런 = 2 + 1 = 3 · 파라미터 11. 손글씨: 입력→은닉 784 × 16 = 12,544, 은닉→출력 16 × 10 = 160, 선 합 12,704 · 뉴런 16 + 10 = 26 · 파라미터 12,730.
자주 틀림① 그림 ①의 선을 셀 때 6개가 아니라 5개로 센다(교차하는 선을 하나로 봄). 선 하나하나에 번호를 매기게 한다. ② 뉴런을 셀 때 입력까지 넣는다. "입력은 값이 들어오는 자리라 편향이 없다"를 짚는다. ③ 손글씨 칸에서 784 × 10처럼 입력과 출력을 바로 곱한다. 선은 바로 옆 층끼리만 잇는다는 것을 그림 ②에서 손가락으로 따라가게 한다.
팁세고 나서 "선의 개수 = 앞층 × 뒤층"을 정리해 준다. 순서가 중요하다. 공식을 먼저 주면 학생은 그림을 보지 않는다. 학생이 센 뒤 미리 16으로 맞춰 둔 앱 C2를 열어 파라미터 수 12,730개를 함께 확인한다. C2의 기본 은닉층은 4라서 그대로 두면 3,190개로 나온다.
1-5딥러닝 그림 읽기
정답은닉층 3층 · 층마다 뉴런 4, 4, 3, 2 · 인공 뉴런 13개 · 선 3 × 4 + 4 × 4 + 4 × 3 + 3 × 2 = 46 · 파라미터 46 + 13 = 59.
자주 틀림① 입력 열까지 층으로 세어 은닉층을 4층으로 답한다. ② 출력 열까지 은닉층으로 넣는다. ③ 인공 뉴런에 입력 3개를 더해 16으로 센다. ④ 선을 셀 때 3 × 4 × 4 × 3 × 2처럼 층을 모두 곱한다. 선은 바로 옆 열끼리만 잇는다는 것을 짚는다.
팁학생이 표를 채운 뒤 미리 열어 둔 #/c2?hidden=16,16,16 탭으로 바꾼다. 화면의 신경망이 활동지 그림 ③처럼 세 층이 되고, 파라미터 수가 12,730에서 13,274로 바뀐다. 층을 쌓으면 깊어지고 파라미터가 늘어난다는 것을 화면으로 확인하는 지점이다.

세션 2

2-1뉴런 → 뉴런 (직렬)
정답z₁ = 5, h = 5, z₂ = 1·5 − 3 = 2, ŷ = 2.
2-23 × 2 × 1 신경망
정답h₂의 계수 0, 1, 1, −1 · ŷ의 계수 1, 1, −2. h₂ = ReLU(0 + 2 + 1 + (−1)) = ReLU(2) = 2. ŷ = ReLU(3 + 2 + (−2)) = ReLU(3) = 3.
2-3ReLU를 빼면 어떻게 달라지나
정답ReLU 없음: x = 0, 1, 2, 3 → −4, −2, 0, 2 (직선). ReLU 있음: x = 1: h = 1, ŷ = ReLU(−2) = 0 · x = 2: h = 3, ŷ = ReLU(0) = 0 · x = 3: h = 5, ŷ = ReLU(2) = 2 → 0, 0, 0, 2 (꺾인 선). 결론 빈칸: 직선(일차함수도 정답).
자주 틀림ReLU 있음 줄에서 h는 ReLU를 통과시키고 ŷ에서는 잊는다. "뉴런마다 한 번씩, 두 번"을 강조한다.
정답 (식 정리)ŷ = (2x − 1) − 3 = 2x − 4, 일차함수. 이 한 줄이 "활성화 함수 없이는 층을 쌓아도 직선"의 손계산 증명이다.

세션 3

3-1한 점의 오차: 부호와 크기
정답e: −2, −0.5, 0, 1, 2 · e²: 4, 0.25, 0, 1, 4. 음수 = 예측이 정답보다 작다. e의 합 0, e²의 합 8. 고르기: e²의 합.

정답ŷ: 3, 4, 5, 6, 7 · e: 0, −1, −2, −3, −4 · e²: 0, 1, 4, 9, 16. Σe² = 30, MSE = 6. 10배 → e²은 1 → 100, 100배.
팁"직선 ŷ = x + 2를 눈으로 보면 x = 1에서만 정답을 맞히고 오른쪽으로 갈수록 벌어진다"고 말하면 표의 e가 0, −1, −2…로 커지는 이유가 보인다.

세션 4-A

이 세션의 설계세션4-A는 앱 A3의 진행 방식과 동일하게 구성한다. 기울기 값은 앱 화면에 표시된 값을 그대로 사용하고, 방향과 보폭 결정은 학생 몫으로 남긴다. 곡선은 앱 A3의 b 모드와 같은 곡선을 활용하며, 기울기 계산은 4-B에서 다룬다. 앱 A3는 기본이 w 모드이다. #/a3?mode=b 로 열면 처음부터 b 모드이다.
4A-1접선의 방향과 기울기 부호
정답b = 3: 양수, ← · b = 1: 0, 정지. 규칙 발견: → / ← / 반대.
팁학생이 표를 먼저 채운다. 그 뒤 앱 A3 현재 위치 슬라이더로 b = −2, 3, 1을 확인한다. b = 1에서는 접선이 사라지고 기울기 0.000이 표시된다.
4A-2업데이트 식으로 세 step (학습률 η = 0.5)
정답step 2: b = −0.5, 기울기 −1.5, 새 b = −0.5 + 0.75 = 0.25 · step 3: b = 0.25, 기울기 −0.75, 새 b = 0.25 + 0.375 = 0.625. 가까워집니다 / 작아집니다. 빼기 이유: 기울기의 반대 방향으로 가기 위해서다. 기울기가 음수이면 빼기가 더하기가 되어 b가 오른쪽으로 움직인다.
팁세 step을 다 채운 뒤 앱 A3에서 "초기화"를 눌러 b = −2로 되돌리고 "한 step 진행"을 세 번 누른다. 화면의 b가 −0.5 → 0.25 → 0.625로 학생 종이와 똑같이 움직인다. 이 순간이 "앱이 하는 일이 내가 한 계산과 같다"를 확인하는 지점이다.
자주 틀림음수를 빼면서 부호를 놓쳐 −2 − 1.5 = −3.5로 적는다. 시범 칸의 "−2 + 1.5"를 짚어 준다.
4A-3보폭 η를 바꾸면
정답η = 0.05 → 새 b −1.85, 거리 2.85, 느림 · η = 2.0 → 4.0, 거리 3.0, 진동 · η = 2.5 → 5.5, 거리 4.5, 발산. 마지막 두 빈칸: 같습니다 / 늘었습니다.
팁네 값은 앱 A3 아래쪽 칩 네 개(발산 2.5 · 진동 2.0 · 수렴 0.5 · 느림 0.05)와 같은 값이다. 학생이 표를 채운 뒤 칩을 하나씩 눌러 자취를 표시하면 손계산과 같은 움직임이 나온다. 발산 칩에서 빨간 점선이 b = −2에서 그래프 오른쪽 위 모서리로 뻗은 뒤 윗변을 따라 오간다. 카드에 "10 step → L 583.859"가 표시된다. 첫 step을 진행한 뒤의 b = 5.5는 활동지 4A-3에서 구한 값이다. η = 2.0에서 남은 거리가 출발 때와 똑같이 3이라 영원히 양옆을 오간다는 점을 짚는다. 여기서 이 곡선에서는 "보폭이 2를 넘으면 발산"이라는 경계가 나온다.

세션 4-B

이 세션의 설계데이터는 점 (3, 7) 하나이고 앱 A5는 기본 데이터 1개 모드로 시작한다. dw = e·x, db = e 식을 먼저 제시하여 계산에 집중하게 하고, 유도 과정은 다루지 않는다. 궁금한 학생은 앱 A4의 단계 펼치기 카드나 교재 6절 끝 상자를 참고하면 된다. 평균은 점이 여러 개일 때만 필요하므로 데이터 5개 모드에서 보여 준다.
4B-1왜 e에 x가 곱해지나
정답w₁만 1.5: 1.5·2 + 1·3 + 0 = 6, 늘어난 양 1 · w₂만 1.5: 1·2 + 1.5·3 + 0 = 6.5, 늘어난 양 1.5. 더 크게 변한 쪽: 입력 3. 늘어난 양 = 0.5 × 3 = 1.5.
팁학생이 표를 채운 뒤 앱 A1에서 w₁ 슬라이더를 1.5로 올렸다가 되돌리고, 이어서 w₂를 1.5로 올린다. 화면의 z가 5 → 6, 5 → 6.5로 움직이는 것을 함께 본다. ReLU를 거쳐도 z가 양수라 ŷ도 같은 값이다. "같은 만큼 움직였는데 입력이 큰 쪽이 더 흔들린다"가 이 문항의 전부이고, 이것이 곧 e에 x를 곱하는 이유다.
4B-2한 step ① 예측과 오차 (출발점 w = 0, b = 0)
정답ŷ = 0 · e = −7.
4B-3한 step ② 기울기
정답dw = (−7) × 3 = −21 · db = (−7) × 1 = −7. 모두 음수 → w, b를 키워야 한다.
4B-4한 step ③ 업데이트 (η = 0.05)
정답새 w = 0 − 0.05 × (−21) = 0 + 1.05 = 1.05 · 새 b = 0 − 0.05 × (−7) = 0 + 0.35 = 0.35.
4B-5한 step ④ 확인: 손실이 정말 줄었나
정답ŷ = 1.05 × 3 + 0.35 = 3.5 · e = 3.5 − 7 = −3.5 · e² = 12.25 · L = 6.125. 손실 24.5 → 6.125, 줄었습니다. 반대, 학습률(η).
팁앱 A5는 단계마다 그 단계까지 계산한 값만 보여 준다. 예측 단계에서는 ŷ만, 오차 단계부터 e, 기울기 단계부터 e·x와 dw·db가 보인다. 아직 계산하지 않은 값은 표에 ?로 표시된다. 그래서 앱이 활동지 뒤 문항의 답을 미리 보여 주지 않는다. 종이로 한 단계를 계산한 뒤 같은 단계를 앱에서 확인하며 함께 진행해도 되고, 4B-5까지 종이로 마친 뒤 한꺼번에 확인해도 된다. 데이터 1개 모드에서 "다음 단계 →"를 누르면 오차, 기울기(dw = −21, db = −7), 업데이트 순서로 진행된다. 한 번 더 누르면 w = 1.05, b = 0.35, 손실이 24.5에서 6.125로 바뀐다. 기울기 단계에서 빨간 점선 화살표(역전파)가 ŷ → ReLU → Σ → dw·db 순서로 차례로 나타난다. ReLU → Σ 화살표 아래에 e = −7, dw 배지 아래에 e × x = (−7) × 3, db 배지 옆에 e = −7이 표시된다. 이 값은 지금의 w·b로 계산되어 step이 바뀌면 함께 바뀐다(둘째 step에서는 e = −3.5). "한 step 통째로"는 네 단계를 0.6초씩 차례로 보여 준 뒤 업데이트를 적용하고, 도는 동안 다른 버튼은 눌리지 않는다. 자동 학습을 켜면 약 2초 뒤 w ≈ 2.1, b ≈ 0.7에서 값이 더 바뀌지 않는다. 자동 학습은 스스로 멈추지 않으므로 "⏸ 자동 멈춤"을 눌러 멈춘다. 이 값은 정답 w = 2, b = 1이 아니다. 그 이유는 업데이트 방향이 늘 (3, 1)에 비례해 w = 3b 선을 따라가다 3w + b = 7과 만나는 점이기 때문이다. 데이터 5개 모드 자동 학습은 w ≈ 2, b ≈ 1에서 약 40초 걸리며, 평균이 필요한 이유로 연결한다.
도전두 번째 step (먼저 끝난 사람만)
정답w = 1.05, b = 0.35 · ŷ = 1.05 × 3 + 0.35 = 3.5 · e = −3.5 · dw = −3.5 × 3 = −10.5 · db = −3.5. 새 w = 1.05 + 0.525 = 1.575, 새 b = 0.35 + 0.175 = 0.525. 크기가 작아졌다. 바닥에 가까워질수록 기울기가 0에 가까워지고 한 step의 이동 거리가 짧아진다.

예상 질문

입력층도 층인가요? 이 그림은 몇 층 신경망인가요?신경망이 몇 층인지 말할 때는 보통 가중치가 있는 층만 센다. 그래서 그림 ③은 은닉층 세 층과 출력층 한 층을 합해 4층 신경망이라고 부르는 경우가 많다. 자료에 따라 입력층까지 세기도 하므로, 헷갈리지 않게 "은닉층이 몇 층인가"로 묻는다.
왜 절댓값이 아니라 제곱인가절댓값 그래프는 바닥에서 뾰족하게 꺾여 기울기가 정해지지 않고, 바닥 근처에서도 기울기 크기가 같아 step의 이동 거리가 줄지 않는다. 제곱은 바닥에 가까울수록 기울기가 0에 가까워져 step의 이동 거리가 저절로 작아진다. 4A-2의 step마다 b가 움직인 거리 1.5 → 0.75 → 0.375가 그 예다.
30억 개를 어떻게 한꺼번에 고치나파라미터마다 자기 기울기가 있고, 모두 "새 값 = 지금 값 − η × 기울기"를 동시에 적용한다. 기울기는 역전파로 한 번에 구하고, GPU가 수천 개씩 동시에 계산한다.
