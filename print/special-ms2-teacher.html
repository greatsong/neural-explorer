과학고 준비 중학교 2학년 · 120분 연강 또는 100분 · 짝 활동 권장 · 학생용 활동지·교재와 짝을 이룸

0. 학습 목표

  1. 딥러닝 그림을 보고 은닉층(히든 레이어)이 몇 층인지, 인공 뉴런과 파라미터가 몇 개인지 셀 수 있다. "3B 모델"의 뜻을 파라미터 수로 설명할 수 있다. (세션1, 특히 1-4·1-5)
  2. 인공 뉴런과 작은 신경망의 계산(순전파)을 손으로 하고, 활성화 함수가 필요한 이유를 설명할 수 있다. (세션2)
  3. 오차와 손실을 계산하고, 오차를 제곱하는 이유를 설명할 수 있다. (세션3)
  4. 기울기를 구해 파라미터를 한 step 고치고, 손실이 줄어드는 것을 확인할 수 있다. (세션4)

1-3
정답−1 → 0 · 0 → 0 · 2.5 → 2.5 · 7 → 7. 1-2의 z = −2 → ŷ = 0.
1-4
정답3 × 2 × 1: 선 = 입력→은닉 6, 은닉→출력 2, 합 8 · 뉴런 = 2 + 1 = 3 · 파라미터 11. 손글씨: 입력→은닉 784 × 16 = 12,544, 은닉→출력 16 × 10 = 160, 선 합 12,704 · 뉴런 16 + 10 = 26 · 파라미터 12,730. 3B = 30억 (3,000,000,000) 개. 30억 ÷ 12,730 ≈ 235,664 → 약 24만 배. 힌트대로 1만 3천으로 나눈 "약 23만 배"와 "약 20만 배"도 정답 처리.
자주 틀림① 그림 ①의 선을 셀 때 6개가 아니라 5개로 센다(교차하는 선을 하나로 봄). 선 하나하나에 번호를 매기게 한다. ② 뉴런을 셀 때 입력까지 넣는다. "입력은 값이 들어오는 자리라 편향이 없다"를 짚는다. ③ 손글씨 칸에서 784 × 10처럼 입력과 출력을 바로 곱한다. 선은 바로 옆 층끼리만 잇는다는 것을 그림 ②에서 손가락으로 따라가게 한다.
팁세고 나서 "선의 개수 = 앞층 × 뒤층"을 정리해 준다. 순서가 중요하다. 공식을 먼저 주면 학생은 그림을 보지 않는다. 학생이 센 뒤 미리 16으로 맞춰 둔 앱 C2를 열어 파라미터 수 12,730개를 함께 확인한다. C2의 기본 은닉층은 4라서 그대로 두면 3,190개로 나온다.
팁여기서 "3B = 30억 개의 w와 b"를 칠판에 크게 적고 마무리까지 지운다. 오프닝의 질문이 이 순간 처음으로 구체적인 뜻을 갖는다.
1-5
정답은닉층 3층 · 층마다 뉴런 4, 4, 3, 2 · 인공 뉴런 13개 · 선 3 × 4 + 4 × 4 + 4 × 3 + 3 × 2 = 46 · 파라미터 46 + 13 = 59.
자주 틀림① 입력 열까지 층으로 세어 은닉층을 4층으로 답한다. ② 출력 열까지 은닉층으로 넣는다. ③ 인공 뉴런에 입력 3개를 더해 16으로 센다. ④ 선을 셀 때 3 × 4 × 4 × 3 × 2처럼 층을 모두 곱한다. 선은 바로 옆 열끼리만 잇는다는 것을 짚는다.
팁학생이 표를 채운 뒤 앱 C2에서 "+ 은닉층 추가"를 두 번 누르고, 새로 생긴 두 층(8, 4)의 숫자 칸에 16을 입력해 세 층을 모두 16으로 맞춘다. 화면의 신경망 그림이 활동지 그림 ③처럼 세 층이 되고, 파라미터 수가 12,730에서 13,274로 바뀐다. "층을 쌓으면 깊어지고, 파라미터가 늘어난다"를 화면으로 확인하는 지점이다. 확인한 뒤에는 은닉층을 16 한 층으로 되돌려 둔다.

정답ReLU 없음: x = 0, 1, 2, 3 → −4, −2, 0, 2 (직선). ReLU 있음: x = 1: h = 1, ŷ = ReLU(−2) = 0 · x = 2: h = 3, ŷ = ReLU(0) = 0 · x = 3: h = 5, ŷ = ReLU(2) = 2 → 0, 0, 0, 2 (꺾인 선). 결론 빈칸: 직선.

정답 (식 정리)ŷ = (2x − 1) − 3 = 2x − 4, 일차함수. 이 한 줄이 "활성화 함수 없이는 층을 쌓아도 직선"의 손계산 증명이다.

팁"직선 ŷ = x + 2를 눈으로 보면 x = 1에서만 정답을 맞히고 오른쪽으로 갈수록 벌어진다"고 말하면 표의 e가 0, −1, −2…로 커지는 이유가 보인다.

세션 4-A

이 세션의 설계활동지 4-A는 앱 A3의 b 모드와 완전히 같은 문제다. w를 2로 고정하고 b만 움직이므로 다섯 점의 오차가 모두 b − 1로 같아지고, 손실이 L = ½(b − 1)² 한 줄로 정리된다. 그래서 학생이 종이에 적은 손실·기울기·갱신 결과가 화면 숫자와 하나도 어긋나지 않는다. 앱은 w 모드로 열리므로 시작 전에 b 모드로 바꿔 둔다.
4A-1다섯 점의 오차 구하기 — 정답
정답x = 2: y = 5, ŷ = 4 + b, e = (4 + b) − 5 = b − 1 · x = 3: y = 7, ŷ = 6 + b, e = b − 1 · 어떤 x든: b − 1. 빈칸: b − 1. 사슬: MSE = (b − 1)², L = ½(b − 1)² · b = −2: e −3, MSE 9, L 4.5.
팁여기가 4-A의 핵심이다. ŷ = 2x + b 와 y = 2x + 1 을 나란히 써 놓고 빼면 2x가 지워진다는 것을 칠판에서 한 번 보여 준다. x가 사라졌기 때문에 다섯 점을 따로 계산할 필요가 없어지고, 손실이 포물선 한 줄로 단순해진다. 이 발견이 없으면 뒤의 계산이 전부 다섯 배로 늘어난다.
4A-2양옆 살펴보기 — 정답
정답b = 0: 왼쪽 2, 지금 0.5, 오른쪽 0 → → · b = 1: 0.5, 0, 0.5 → 정지 · b = 3: 0.5, 2, 4.5 → ←.
4A-3기울기와 ½의 이유 — 정답
정답기울기: b = 0 → (0 − 2) ÷ 2 = −1 · b = 1 → 0 · b = 3 → (4.5 − 0.5) ÷ 2 = 2. 아랫줄 b − 1 도 −1, 0, 2 로 같다.
정답 (½ 확인)½ 없이 (b − 1)² 로 두면: b = 0 → (0 − 4) ÷ 2 = −2 · b = 3 → (9 − 1) ÷ 2 = 4. 늘 2배로 나온다. 규칙: 음수일 때 →, 양수일 때 ←, 즉 반대 방향.
팁½은 지금까지 근거 없이 곱해 둔 값이었는데 여기서 학생이 직접 근거를 만든다. ½이 없으면 기울기에 2가 따라붙고, ½을 곱해 두면 b − 1 한 줄로 끝난다. 미분을 배우면 이 2가 어디서 오는지 알게 된다고만 덧붙이고 넘어간다. 시간이 부족하면 이 ½ 확인 상자만 건너뛴다.
4A-4갱신 세 걸음 — 정답
정답걸음 2: b = −0.5, 기울기 −1.5, 새 b = −0.5 + 0.75 = 0.25 · 걸음 3: b = 0.25, 기울기 −0.75, 새 b = 0.25 + 0.375 = 0.625. 가까워집니다 / 작아집니다. 빼기 이유: 기울기의 반대 방향으로 가기 위해서다. 기울기가 음수이면 빼기가 더하기가 되어 b가 오른쪽으로 움직인다.
팁세 걸음을 다 채운 뒤 앱 A3에서 "한 step 진행"을 세 번 누른다. 화면의 b가 −0.5 → 0.25 → 0.625로 학생 종이와 똑같이 움직인다. 이 순간이 "앱이 하는 일이 내가 한 계산과 같다"를 확인하는 지점이다.
자주 틀림음수를 빼면서 부호를 놓쳐 −2 − 1.5 = −3.5로 적는다. 시범 칸의 "−2 + 1.5"를 짚어 준다.
4A-5보폭 η 네 가지 — 정답
정답η = 0.05 → 새 b −1.85, 거리 2.85, 느림 · η = 2.0 → 4.0, 거리 3.0, 진동 · η = 2.5 → 5.5, 거리 4.5, 발산. 마지막 두 빈칸: 같습니다 / 늘었습니다.
팁네 값은 앱 A3 아래쪽 칩 네 개(발산 2.5 · 진동 2.0 · 수렴 0.5 · 느림 0.05)와 같은 값이다. 학생이 표를 채운 뒤 칩을 하나씩 눌러 자취를 표시하면 손계산과 같은 움직임이 나온다. 다만 발산 칩은 첫 걸음이 b = 5.5라 그래프 오른쪽 밖으로 나가 자취가 보이지 않는다. 활동지 4A-5에서 구한 5.5가 바로 그 값이라고 짚는다. η = 2.0에서 남은 거리가 출발 때와 똑같이 3이라 영원히 양옆을 오간다는 점을 짚는다. 여기서 "보폭이 2를 넘으면 발산"이라는 경계가 나온다.

세션 4-B

4B-1
정답w₁만 1.5: 1.5·2 + 1·3 + 0 = 6, 늘어난 양 1 · w₂만 1.5: 1·2 + 1.5·3 + 0 = 6.5, 늘어난 양 1.5. 더 크게 변한 쪽: 입력 3. 늘어난 양 = 0.5 × 입력. 4B 데이터: x = 5에서 0 → 0.5, 움직인 양 0.5. 정리 빈칸: 5배. 4-A와 이어 보기: w 줄 오른쪽 8, (8 − 50) ÷ 2 = −21, e × x = −21 · b 줄 왼쪽 32, 오른쪽 18, (18 − 32) ÷ 2 = −7, e × 1 = −7. 같습니다.
팁학생이 표를 채운 뒤 앱 A1에서 w₁ 슬라이더를 1.5로 올렸다가 되돌리고, 이어서 w₂를 1.5로 올린다. 화면의 z가 5 → 6, 5 → 6.5로 움직이는 것을 함께 본다. ReLU를 거쳐도 z가 양수라 ŷ도 같은 값이다. "같은 만큼 움직였는데 입력이 큰 쪽이 더 흔들린다"가 이 문항의 전부이고, 이것이 곧 e에 x를 곱하는 이유다.
4B-2
정답e: −3, −5, −7, −9, −11 (합 −35) · e × x: −3, −10, −21, −36, −55 (합 −125) · e²: 9, 25, 49, 81, 121 (합 285). 손실 = (285 ÷ 2) ÷ 5 = 28.5. 앱 A5 화면의 시작 손실과 같은 숫자다.
4B-3
정답dw = −125 ÷ 5 = −25 · db = −35 ÷ 5 = −7. 모두 음수 → w, b를 키워야 한다.
4B-4
정답새 w = 0 − 0.05 × (−25) = 0 + 1.25 = 1.25 · 새 b = 0 − 0.05 × (−7) = 0 + 0.35 = 0.35. 가까워졌습니다.
4B-5
정답ŷ = 1.25 × 3 + 0.35 = 4.1 · e = 4.1 − 7 = −2.9 · e² = 8.41. 49 → 8.41, 줄었습니다. 다섯 점 전체 손실은 28.5 → 4.77(뒤의 값은 앱 화면 4.7675를 읽어 적는다). 1958 연결: 반대, 학습률(η).
팁앱 A5는 4B를 진행하면서 함께 보여 준다. 4B-2를 마치면 "다음 단계 →"를 눌러 오차 화면을, 4B-3 뒤에 기울기 화면(dw = −25, db = −7)을 보여 준다. 4B-4 뒤에 한 번 더 눌러 갱신 식을 보여 주고, 다시 한 번 눌러 w = 1.25, b = 0.35로 바꾼다. 학생은 이때 화면의 손실 4.7675를 읽어 4B-5에 적는다. 4B-5가 끝나면 "▶ 자동 학습"으로 20~30 step을 돌린다. 이때 w는 금방 2 근처로 가지만 b는 30 step에서 약 0.68로, 1에 가까워지려면 200 step 넘게 걸린다.
팁활동지 4B-2의 손실 28.5와 4B-5의 4.77이 앱 A5 화면에 그대로 표시된다. 4-A에서 ½을 도입해 둔 덕분에 종이와 화면이 끝까지 같은 숫자로 간다. 학생이 "왜 285를 2로도 나누고 5로도 나누나요"라고 물으면, 2로 나누는 것은 4-A에서 확인한 ½이고 5로 나누는 것은 다섯 점의 평균이라고 나누어 답한다.

마무리

끝-1
정답파라미터 2개 · 3B = 30억 개 · 파라미터 수 × step 수 × 데이터 양.
끝-2
평가 기준세 단어(크기·비용·목적)를 모두 쓰고, "무조건 큰 것이 좋다"에서 "목적에 맞는 크기"로 생각이 옮겨 갔는지를 본다. 예: "250B는 더 복잡한 패턴을 표현하지만 학습 비용과 전기가 그만큼 든다. 휴대폰 안에서 돌려야 하면 3B가 맞다. 좋은 모델은 목적에 맞는 크기다."
끝-3
평가 기준다섯 단어가 모두 들어가고 순서가 예측 → 오차 → 기울기 → 갱신이면 만점. 학습률이 "보폭"의 뜻으로 사용되었는지 확인한다. 예: "뉴런은 입력에 가중치를 곱하고 편향을 더해 예측을 만든다. 예측과 정답의 차이가 오차다. 오차로 기울기를 구하면 어느 쪽으로 고쳐야 하는지 알 수 있다. 기울기의 반대 방향으로, 학습률과 기울기를 곱한 만큼 가중치를 갱신한다. 이것을 반복하면 오차가 줄어든다."

예상 질문

입력층도 층인가요? 이 그림은 몇 층 신경망인가요?신경망이 몇 층인지 말할 때는 보통 가중치가 있는 층만 센다. 그래서 그림 ③은 은닉층 세 층과 출력층 한 층을 합해 4층 신경망이라고 부르는 경우가 많다. 자료에 따라 입력층까지 세기도 하므로, 헷갈리지 않게 "은닉층이 몇 층인가"로 묻는다.
왜 절댓값이 아니라 제곱인가절댓값 그래프는 바닥에서 뾰족하게 꺾여 기울기가 정해지지 않고, 바닥 근처에서도 기울기 크기가 같아 걸음이 줄지 않는다. 제곱은 바닥에 가까울수록 기울기가 0에 가까워져 걸음이 저절로 작아진다. 4A-4의 걸음 1.5 → 0.75 → 0.375가 그 예다.
30억 개를 어떻게 한꺼번에 고치나파라미터마다 자기 기울기가 있고, 모두 "새 값 = 지금 값 − η × 기울기"를 동시에 적용한다. 기울기는 역전파로 한 번에 구하고, GPU가 수천 개씩 동시에 계산한다.
