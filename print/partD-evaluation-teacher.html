1-B MAE
MAE = ( |잔차₁| + … + |잔차₅| ) / N
MAE = 0.9 / 5 = 0.18 °C
해설
이 표는 단순해서 |잔차| 합 = 잔차 합. 학생들이 "잔차 부호가 다르면 절대값이 필요한 이유"를 직관으로 잡을 수 있도록 안내.
1-C MSE · RMSE
MSE = 0.25 / 5 = 0.05 °C²
RMSE = √0.05 = 0.2236 °C (≈ 0.22)
RMSE는 MAE보다 큰가요, 작은가요?
답: 크다 (0.22 > 0.18). 이유: 0.4라는 비교적 큰 잔차 하나가 제곱돼서 RMSE에 영향이 커짐 — RMSE가 MAE보다 크면 일부 점에 큰 오차가 몰려 있다는 신호.

2-B 네 지표
정확도 = (3 + 4) / 10 = 0.70
정밀도 = 3 / (3 + 1) = 3 / 4 = 0.75
재현율 = 3 / (3 + 2) = 3 / 5 = 0.60
F1 = 2 · 0.75 · 0.60 / (0.75 + 0.60) = 0.9 / 1.35 = 0.667
어느 쪽 실수가 더 많은가? — FN (놓침). 가장 낮은 지표 — 재현율 (0.60)
해설
이 모델은 실제 양성 5명 중 2명을 놓침 — 재현율이 약함. 시나리오에 따라 이 모델은 암 검진에는 부적합하고, 스팸 필터에는 적합할 수 있음.
2-C 시나리오

㉠ 코로나 PCR — 권장 답: 모델 A

근거
FN(감염자 놓침)이 지역 사회 위험으로 직결. 재현율 우선. 모델 A 재현율 0.96 vs B 0.85. FP는 추가 검사로 안전망 있음 — A의 낮은 정밀도(0.444)는 감수 가능.

㉡ 공장 품질 — 권장 답: 상황에 따라 A 또는 B (둘 다 합리적)

근거 — A를 고르면
F1이 더 높고(0.87), 폐기되는 정품 수가 적어 원가 효율적. 일반 제품에 적합.
근거 — B를 고르면
FN(불량 출하)이 치명적인 제품군(의료기기, 안전 부품 등)이라면 정밀도를 희생하고 재현율(0.983)을 최대화. 정상품 폐기 손실은 회수 불가 사고보다 작음.
채점 기준
A·B 어느 쪽을 골라도 FN과 FP 비용을 명시적으로 비교하고 그에 따라 지표 선택을 정당화하면 정답.
2-D 임계값을 옮기면

임계값 = 0.50

양성 판정: P1(0.92), P2(0.81), P3(0.65), P4(0.58) — 4명
P1·P2·P3 = TP, P4 = FP, P5 = FN, P6·P7·P8 = TN

관찰 — 정답
임계값을 낮추면 재현율이 올라가고 정밀도가 내려간다.
임계값을 높이면 정밀도가 올라가고 재현율이 내려간다.
F1이 가장 큰 임계값은 위 세 가지 중 0.30.
교사 메모
정확도는 세 임계값 모두 0.75로 같다는 점이 흥미로움. 학생들이 "정확도가 같으면 같은 모델 같다"고 오해할 수 있으니, 정밀도·재현율·F1을 함께 봐야 한다는 점을 강조.

섹션 3. 종합 — 적용·서술

3-A 정확도만으로 판단할 수 없는 이유
기대 답 (예시)
① 양성·음성 비율이 한쪽으로 치우치면 정확도가 높아도 양성을 거의 못 잡을 수 있다 (예: 양성 1% 데이터에서 "모두 음성" 답하면 정확도 99%).
② 어떤 실수가 더 아픈지에 따라 좋은 모델이 다르기 때문에, 한 숫자만으로는 "이 모델이 우리 상황에 맞는가"를 판단할 수 없다.
3-B 학생 시나리오 (개방형)
채점 기준
학생이 새 문제를 떠올렸다는 점, FN·FP 비용을 명시적으로 비교했다는 점, 그에 맞는 지표(재현율/정밀도/F1)를 골랐다는 점 — 세 가지가 모두 보이면 만점. 학생 예시: "지진 조기 경보 — FN(놓침)이 생명 손실, 재현율 우선" / "유튜브 추천 — FP(흥미 없는 영상 추천)와 FN(좋아할 영상 못 만남) 둘 다 무거움, F1 균형" 등.
