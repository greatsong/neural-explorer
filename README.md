# 🧠 Neural Explorer

코드 없이 슬라이더와 그림판으로 신경망부터 LLM 첫걸음까지 배우는 16단계 인터랙티브 학습 앱.

대상: 고등학생 (수업 5~6차시 + 활동지)

## 커리큘럼 구성

**A. 단일 인공 뉴런의 학습**
- A1 인공 뉴런의 예측 (가중치·편향·활성화)
- A2 오차와 MSE
- A3 경사하강법 (학습률 포함)
- A4 기울기 계산하기 (e·x 패턴)
- A5 전체 흐름 완성 (예측 → 오차 → 기울기 → 갱신)
- A6 기온 예측 프로젝트 (서울 1908~2025 회귀)

**B. 분류 문제 해결하기**
- B1 문제 정의와 라벨 (세모 vs 네모)
- B2 데이터셋과 전처리
- B3 학습 / 평가 데이터 나누기
- B4 이진 분류 모델 학습 (시그모이드 + BCE)

**C. 딥러닝으로 손글씨 분류**
- C1 MNIST 데이터셋 소개
- C2 미니 MNIST 도전 (300장 실제 학습)

**D. 모델을 어떻게 평가할까**
- D1 회귀 평가 (잔차·MAE·RMSE·R², A6 데이터 재활용)
- D2 분류 평가 (혼동행렬·정확도·정밀도·재현율·F1·임계값, 시나리오 4종)
- 활동지: `print/partD-evaluation-{student,teacher,student-problems}.html`

**E. 언어를 다루는 신경망 — LLM 첫걸음**
- E1 글자가 숫자가 되기까지 (인코딩, 원-핫)
- E2 단어를 좌표로 (임베딩 직관)
- E3 의미가 가까운 단어 찾기 (Word2Vec 미니, 브라우저 학습)
- E4 다음 단어 맞히기 (LLM = 다중분류 + 소프트맥스)
- 활동지: `print/partE-llm-student.html`

**히든 스테이지** — 메인 카드에서 진입
- 자기주도 심층 탐구 (13개 주제 카드)
- 5부 생성 — 13. 평균과 분포 · 14. 오토인코더 (C2 + D2 + E4 완료 시 포털)
- 6부 잔여 — 16. 토큰 · 19. 시퀀스 · 20. 어텐션 · 21. 멀티헤드 트랜스포머 (5부 완료 시 포털)

## 개발

```bash
npm install
npm run dev      # http://localhost:4035
npm run build
```
