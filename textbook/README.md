# 신경망 첫걸음 — 자기주도 교재 1부

> 단일 뉴런의 한 step에서 시작해, 분류 모델을 만들고, 작은 손글씨 신경망을 직접 학습시키기까지.
> 한 권으로 인공지능이 **"스스로 더 잘하게 되는 원리"** 를 끝까지 따라가는 자기주도 학습 교재.

이 교재는 **Neural Explorer 앱** 의 공개된 A·B·C 영역 12개 페이즈를 자기주도 학습용으로 풀어 쓴 마크다운 책이에요. 옆에 앱을 띄워 놓고 한 챕터씩 읽으며 슬라이더를 직접 움직이는 방식으로 사용합니다.

## 누구를 위한 책인가

- 인공지능이 어떻게 작동하는지를 **계산할 수 있는 무엇** 으로 이해하고 싶은 고등학교 1·2학년
- 수업이나 강의를 보충해 혼자서 한 번 더 따라가 보고 싶은 학생
- 코드를 써본 적 없어도 괜찮아요. 이 책은 코드 대신 **숫자와 슬라이더** 로 갑니다.

## 사용법

각 챕터는 다음 6개 섹션으로 통일되어 있어요.

1. **들어가며** — 이번 챕터에서 답할 질문
2. **핵심 아이디어** — 직관 한 컷
3. **차근차근** — 개념을 작은 덩어리로
4. **손으로 따라하기** — 작은 숫자로 직접 계산 (정답은 펼치기 안)
5. **앱에서 확인하기** — 앱의 어느 슬라이더를 어떻게
6. **스스로 점검** — 객관식·단답·서술 3~4문항 (정답은 펼치기 안)

한 챕터당 **30~40분** 을 쓰면 충분히 자기 것으로 만들 수 있어요.

## 책의 약속

> **모르는 단어가 나오면 책이 잘못 쓴 거예요.**

이 책은 한 챕터에서 다음 챕터로 넘어갈 때 **그 시점까지 배운 것만으로** 설명되도록 쓰여 있어요. 갑자기 어려워졌다면 한 챕터 앞으로 돌아가 보세요.

## Neural Explorer 앱

각 챕터에는 그 챕터에 해당하는 앱 페이지로 가는 링크가 들어 있어요. 앱은 별도 설치 없이 웹브라우저에서 바로 열립니다. 휴대폰에서도 열리지만 슬라이더를 정밀하게 움직여야 하는 부분이 많아 **노트북·데스크탑** 을 권합니다.
