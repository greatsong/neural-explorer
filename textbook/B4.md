# B4. 이진 분류 모델 학습

> 출력 점수 하나를 0~1 사이로 짜내고, 0.5를 기준으로 세모와 네모를 가릅니다. 한 step의 흐름은 A에서 본 그대로예요.

[B4를 앱에서 열기](https://neural-explorer-six.vercel.app/#/b4)

## 들어가며

B1~B3을 거치며 우리는 데이터를 정의하고, 더러운 표본을 빼내고, 학습용/평가용으로 나누었어요. 모든 준비가 끝났어요. 이제 모델 한 개를 직접 학습시킬 차례입니다.

기억나죠. A 영역에서 한 step의 흐름은 이거였어요.

```
예측 → 오차 → 기울기 → 갱신
```

A 영역의 뉴런은 입력 한 개를 받아 숫자를 예측했어요. 이번에는 입력이 64개고, 답은 두 종류 중 하나입니다.

이번 챕터에서 답할 질문은 두 가지예요.

> 1. 출력 뉴런 하나로 어떻게 두 종류를 가를까요?
> 2. 분류에서는 오차를 어떻게 잴까요?

## 1. 핵심 아이디어

라벨이 두 개니까 출력 뉴런도 한 개면 충분해요. 이 한 뉴런이 64개 입력에 가중치를 곱해 더한 점수 하나를 만들어요. 이 점수를 우리는 `z`라고 부를게요.

문제는, `z`는 `−13.2`나 `+8.7`처럼 아주 큰 음수일 수도 큰 양수일 수도 있어요. 우리가 원하는 답은 "세모(0)인지 네모(1)인지"잖아요. 그래서 `z`를 **0과 1 사이**로 짜내는 장치가 필요해요. 이 장치를 **시그모이드**라고 불러요.

> **시그모이드**: 어떤 숫자도 받아서 0~1 사이 값으로 짜내 주는 함수. `σ(z)`로 적어요. `z`가 아주 작으면 0에 가깝고, 아주 크면 1에 가깝고, 0이면 정확히 0.5예요.

이렇게 짜낸 값 `σ(z)`를 우리는 "네모일 확률"로 읽어요. 그리고 약속을 하나 정합니다.

> `σ(z)` ≥ 0.5 이면 네모로, 0.5 미만이면 세모로 답하자.

이 0.5의 자리를 **결정 경계**라고 불러요. 점수 `z`로 따지면 정확히 `z = 0`이 결정 경계예요. (`σ(0) = 0.5`니까요.)

> **결정 경계**: 모델이 답을 바꾸는 경계. 이 책의 이진 분류에서는 `σ(z) = 0.5`(즉 `z = 0`).

학습이란 결국 **`z`를 잘 만드는 가중치를 찾는 일**이에요. 세모 그림이 들어오면 `z`가 음수가 되고, 네모 그림이 들어오면 양수가 되도록.

## 2. 차근차근

### 2.1 한 그림이 모델을 통과하는 모습

세모 그림 한 장이 들어가면 어떻게 답이 나오는지 따라가 볼게요.

1. 그림은 64개의 0과 1 묶음이에요. 이걸 입력으로 보내요.
2. 출력 뉴런은 입력 칸마다 가중치를 곱해서 모두 더해요. 거기에 편향을 한 번 더해서 점수 `z`를 만들어요.
3. 시그모이드가 `z`를 받아 `σ(z)`로 짜내요. 0~1 사이의 숫자.
4. `σ(z) ≥ 0.5`면 모델은 "네모(1)"라고 답하고, 0.5 미만이면 "세모(0)"라고 답해요.

A 영역의 뉴런과 비교하면 차이는 두 가지예요.

- 입력이 64개로 늘었어요.
- 점수 `z` 뒤에 시그모이드 한 단계가 더 붙었어요.

다른 모든 것 — 예측, 오차, 기울기, 갱신의 한 step 흐름 — 은 똑같아요.

### 2.2 시그모이드 함수의 모양

시그모이드를 식으로 적으면 이래요.

$$\sigma(z) = \frac{1}{1 + e^{-z}}$$

$e$는 약 2.718쯤 되는 상수, $e^{-z}$는 "$e$를 $-z$제곱한 값"이에요. 식이 낯설면 일단 **모양**만 머리에 넣어 두세요.

- `z`가 아주 작은 음수(예: −10)면 `σ(z)`는 0에 거의 붙어요.
- `z`가 0이면 `σ(z) = 0.5`예요.
- `z`가 아주 큰 양수(예: +10)면 `σ(z)`는 1에 거의 붙어요.

가운데(0 근처)에서는 부드럽게 휘는 S자 곡선이에요. 그래서 `z`가 살짝만 바뀌어도 답(σ)이 부드럽게 바뀌어요. 이 부드러움 덕분에 **기울기 계산이 가능**해요. A3에서 봤던 경사하강법이 작동할 수 있는 거예요.

### 2.3 분류에서는 오차를 어떻게 재나

A2에서 우리는 오차로 평균 제곱 오차(MSE)를 썼어요. (예측 − 정답)을 제곱해 평균. 회귀에는 잘 맞는 방법이었죠.

분류에서는 사정이 조금 달라요. 정답이 0 아니면 1이고, 모델 출력은 0~1 사이 확률이에요. 이 상황에 잘 어울리는 손실이 따로 있어요. 이름은 **이진 크로스 엔트로피**라고 해요.

이 손실은 한 줄로 외워 두면 충분해요.

> **모델이 정답에 자신 있을수록 손실은 작고, 정답을 놓치면 손실은 가파르게 커진다.**

예를 들어 어떤 그림의 정답이 1(네모)인데 모델이 `σ(z) = 0.99`라고 답했다면 손실은 아주 작아요. `σ(z) = 0.5`처럼 헷갈리면 손실은 중간쯤. `σ(z) = 0.01`처럼 완전히 틀렸다면 손실이 매우 커져요.

식 유도까지는 가지 않을게요. 우리에게 필요한 건 **분류에는 분류용 손실이 따로 있고**, 그 이름이 이진 크로스 엔트로피이며, 동작 원리가 위 한 줄이라는 것까지예요. 앱에서는 손실 곡선이 학습이 진행될수록 떨어지는 모습을 직접 볼 수 있어요.

A 영역에서 익힌 한 step의 흐름은 그대로예요.

```
예측 → 오차 → 기울기 → 갱신
```

오차 재는 식만 ½MSE 대신 이진 크로스 엔트로피로 바뀌었을 뿐, 나머지는 똑같이 작동합니다.

### 2.4 미니배치와 epoch — 한 번에 여러 장씩, 데이터를 여러 번

A5에서는 한 step이 보통 표본 한 개나 표본 전체에 대한 거였어요. 실제로는 그 사이의 절충안을 많이 써요.

- **미니배치**: 학습 데이터 중 한 번에 묶어서 처리하는 작은 묶음. 이 책의 앱은 16장씩 묶어요. 16장의 예측·오차를 평균 내서 가중치를 한 번 갱신해요.
- **epoch (학습회차)**: 학습 데이터를 한 번 다 본 횟수. 만약 학습용이 96장이고 미니배치가 16장이면, 한 epoch에 6번의 갱신이 일어나요. 100 epoch면 100번씩 데이터를 훑으니까 600번 갱신.

미니배치를 쓰는 이유는 두 가지예요. 한 장씩 갱신하면 너무 출렁이고, 전체를 한꺼번에 쓰면 너무 느려요. 그 사이에서 안정적으로 빠르게 학습되는 게 미니배치예요.

### 2.5 학습률 η — A에서 본 그 보폭

학습률은 A3에서 본 그 보폭이에요. 한 번 갱신할 때 가중치를 얼마나 옮길지 정하는 숫자.

- 너무 크면 손실이 출렁여서 잘 안 줄어요.
- 너무 작으면 너무 천천히 학습돼서 시간이 오래 걸려요.

이 책의 앱에서 기본 학습률은 0.05예요. 작은 숫자죠. 슬라이더로 0.005~0.2 사이를 직접 움직여 볼 수 있어요.

### 2.6 학습 곡선 읽기 — 손실·학습 정확도·평가 정확도

학습이 진행되면 매 epoch마다 세 숫자가 기록돼요.

- **손실 (오렌지 곡선)**: 매 미니배치의 평균 손실. epoch가 늘수록 떨어지는 게 정상이에요.
- **학습 정확도 (녹색)**: 학습용 데이터에서의 정확도. 보통 시간이 갈수록 올라가요.
- **평가 정확도 (파랑)**: 평가용 데이터에서의 정확도. **이게 진짜 실력**.

이상적으로는 세 곡선이 모두 좋은 방향(손실은 아래로, 정확도는 위로)으로 가요. 평가 정확도가 학습 정확도와 비슷하게 따라 올라가면 일반화가 잘 된 거예요. 학습 정확도만 계속 오르고 평가 정확도가 정체하면 — B3에서 본 **과적합** 신호예요.

### 2.7 가중치 시각화 — 모델이 진짜 뭘 배웠나

학습이 끝난 모델은 64개 입력 각각에 가중치 하나씩, 모두 64개 가중치를 가져요. 이 64개를 8×8 격자에 색으로 그려 보면 **모델이 뭘 잡았는지** 보여요.

- 파란 칸: 그 자리에 점이 찍히면 답이 네모(1) 쪽으로 끌려가요. (가중치 양수)
- 빨간 칸: 그 자리에 점이 찍히면 답이 세모(0) 쪽으로 끌려가요. (가중치 음수)
- 색이 진할수록 영향이 크고, 옅을수록 작아요.

학습이 잘 된 모델은 이 격자가 **모서리·선의 방향**을 보여줘요. 네모의 곧은 선이 있는 자리에는 파란 칸이 모이고, 세모의 비스듬한 변이 있는 자리에는 빨간 칸이 모여요. 학습 전에는 단지 작은 랜덤 초기값이라서 의미 없는 노이즈 패턴이지만, epoch가 진행되면서 점점 의미 있는 모양으로 변하는 모습이 보여요.

## 3. 손으로 따라하기

### 문제 1. 시그모이드 값 읽기

세 그림에 대해 모델이 만든 점수 `z`가 다음과 같다고 합시다. 각 그림에 대해 `σ(z)`를 0/0.5/1 중 가장 가까운 값으로 답하고, 모델이 어떤 답을 내놓을지(세모인지 네모인지) 적어 보세요.

- 그림 A: `z = +6.2`
- 그림 B: `z = 0`
- 그림 C: `z = −5.5`

<details>
<summary>정답 보기</summary>

- 그림 A: `z`가 큰 양수 → `σ(z)`는 1에 가까움 → 모델 답 **네모**
- 그림 B: `z = 0` → `σ(z) = 0.5` → 정확히 경계. 약속상 `σ(z) ≥ 0.5`이므로 모델 답 **네모**(아슬아슬)
- 그림 C: `z`가 큰 음수 → `σ(z)`는 0에 가까움 → 모델 답 **세모**
</details>

### 문제 2. 결정 경계가 움직이면

학습 초기에는 모든 그림에 대해 `σ(z)`가 0.5 근처(0.45~0.55)로 모여 있다고 해 봐요. 이때 모델은 새 그림 100장 중 몇 장 정도 맞힐까요? (세모 50장, 네모 50장이라고 가정)

<details>
<summary>정답 보기</summary>

대략 **50% 정도**예요. `σ(z)`가 0.5 근처에서 흔들리면 모델은 사실상 동전 던지기로 답을 하는 거예요. 학습이 진행되면서 세모 그림에는 `σ(z)`가 작아지고(0.1쯤) 네모 그림에는 커지는(0.9쯤) 식으로 점수가 벌어져야 정확도가 올라가요.
</details>

### 문제 3. 손실이 큰 경우

어떤 그림의 정답이 1(네모)인데 모델 출력이 `σ(z) = 0.05`였다면, 이 그림에서 손실은 큰가요 작은가요? 이유와 함께 답해 보세요.

<details>
<summary>정답 보기</summary>

손실이 **매우 큼**. 정답이 1인데 모델은 0에 가까운 0.05를 답한 거예요. 즉 "이 그림은 거의 확실히 세모"라고 매우 자신 있게 틀린 답을 내놓은 상태예요. 이진 크로스 엔트로피는 이런 경우에 특히 큰 손실을 주어, 가중치를 크게 흔들어 다음 step에서 더 잘 맞히도록 끌어당깁니다.
</details>

### 4.1 학습 컨트롤 살펴보기

화면 오른쪽의 **학습 컨트롤** 카드에 슬라이더와 체크박스가 있어요.

- **epoch (학습회차)**: 10~80 사이. 기본 40. 학습 데이터를 몇 번 훑을지를 정해요.
- **학습률 η**: 0.005~0.2 사이. 기본 0.05.
- **은닉층 추가** 체크박스: 일단 **체크하지 마세요.** 우리는 이번 챕터에서 출력 뉴런 1개짜리 단순한 모델만 다뤄요. (이 옵션은 다음 영역인 C에서 필요해질 거예요. 호기심에 한 번 켜 봐도 되지만, 본문 학습은 끄고 진행하세요.)

설정은 그대로 두고 **▶ 학습 시작** 버튼을 눌러 보세요.

### 4.2 학습 곡선 관찰

학습이 시작되면 화면 왼쪽에 곡선이 그려져요. 세 가지 곡선이 한 그래프에 있어요.

- **오렌지 곡선 (손실)**: 위에서 아래로 내려가는 모양이 정상.
- **녹색 곡선 (학습 정확도)**: 아래에서 위로 올라가는 모양이 정상.
- **파랑 곡선 (평가 정확도)**: 학습 정확도와 비슷하게 따라 올라가야 함.

오른쪽 위 **정확도** 카드에 학습용·평가용 정확도 숫자가 epoch마다 갱신돼요. 평가 정확도가 80% 이상이 되면 자동으로 완료 처리가 됩니다.

### 4.3 가중치가 의미 있는 모양으로 변해 가는 모습

화면 가운데의 **신경망 구조 + 실시간 가중치** 카드를 잘 보세요. 입력 64뉴런이 세로 한 줄로 늘어서 있고, 64개 가중치 라인이 출력 뉴런 σ로 모이는 모양이에요.

- 학습 전: 라인 색이 무작위로 섞여 있어요. 의미가 없어요.
- 학습이 진행되면 색이 **부호별로 정리**되기 시작해요. 파란 라인(네모 쪽으로 끌어올림)과 빨간 라인(세모 쪽으로 끌어내림)이 점점 또렷이 갈라져요.

오른쪽의 8×8 가중치 히트맵을 눈여겨봐 주세요. 학습이 진행되면서 **모서리·선 방향**이 점점 또렷이 드러납니다. 네모의 변이 있을 자리가 파랗게, 세모의 비스듬한 변 자리가 빨갛게 물들면 학습이 잘 되고 있다는 뜻이에요.

### 4.4 새 그림 시험해 보기

화면 아래의 **새 그림 시험해 보기** 영역에는 평가용 그림(B3의 평가용 묶음)이 한 줄로 들어 있어요. 그림 한 장을 클릭하면 그 그림에 대해 모델이 만든 `z`와 `σ(z)`가 표시돼요.

- 0~1 막대에서 `σ(z)`가 어디에 찍혀 있는지 보세요.
- 0.5 기준선보다 오른쪽이면 모델 답은 네모, 왼쪽이면 세모.
- 정답과 일치하면 초록색 테두리, 틀리면 빨간색 테두리가 나와요.

여러 그림을 클릭해 보면서 모델이 헷갈려하는 그림(σ가 0.5 근처)과 자신 있게 답하는 그림(σ가 0이나 1에 거의 붙은)을 구별해 보세요. 헷갈리는 그림이 학습된 가중치 패턴과 잘 맞지 않는 모양일 거예요.

### 4.5 다양한 설정으로 실험

기본 설정으로 한 번 학습해 봤다면, 컨트롤을 바꿔 가면서 실험해 보세요.

- 학습률을 0.005로 아주 낮게 → 학습이 매우 천천히 됨. 같은 epoch로는 정확도가 덜 올라요.
- 학습률을 0.2로 높게 → 손실이 출렁이거나 정확도가 일정 수준에서 멈춰요.
- epoch를 80까지 올리면 → 학습 정확도는 더 올라가지만 평가 정확도는 더 안 올라갈 수 있어요. (과적합 경향)
- B3에서 평가용 비율을 바꾼 뒤 다시 학습 → 학습용/평가용 그림 수가 달라지면서 결과가 바뀌어요.

### 4.6 (참고) 화면 아래 부록 안내

## 5. 스스로 점검

### 문제 1 (단답)
어떤 숫자도 받아서 0~1 사이 값으로 짜내 주는 함수의 이름은?

<details>
<summary>정답 보기</summary>

**시그모이드** (`σ(z) = 1 / (1 + e^(−z))`).
</details>

### 문제 2 (객관식)
이진 분류에서 모델이 답을 바꾸는 경계는?

(가) `σ(z) = 0`
(나) `σ(z) = 0.5`
(다) `σ(z) = 1`
(라) `z = 1`

<details>
<summary>정답 보기</summary>

**(나)**. `σ(z)` ≥ 0.5이면 한 종류, 0.5 미만이면 다른 종류로 답하기로 약속했어요. 점수 `z`로 따지면 `z = 0`이 같은 자리예요.
</details>

### 문제 3 (서술형)
A 영역에서 본 한 step의 네 단계와 B4의 한 step은 어떤 점이 같고 어떤 점이 다른가요? 두세 문장으로 정리해 보세요.

<details>
<summary>정답 보기</summary>

같은 점은 한 step이 **예측 → 오차 → 기울기 → 갱신**의 네 단계로 이루어진다는 점이에요. A에서 본 그 흐름이 그대로 작동합니다.

다른 점은 두 가지예요. 첫째, 입력이 한 개에서 64개로 늘었고 출력 뉴런 뒤에 시그모이드라는 짜내기 단계가 붙었어요. 둘째, 오차를 재는 방법이 ½MSE에서 분류용 손실(이진 크로스 엔트로피)로 바뀌었어요. 정답에 자신 있을수록 손실이 작아지고, 자신 있게 틀리면 손실이 가파르게 커지는 식으로 동작합니다.
</details>

### 문제 4 (서술형)
학습된 모델의 가중치 격자(8×8)에서 파란 칸과 빨간 칸은 무엇을 뜻하나요? 그리고 이 그림이 또렷한 모서리·선 모양으로 보이면 어떤 의미인가요?

<details>
<summary>정답 보기</summary>

파란 칸은 **그 자리에 점이 찍히면 답이 네모(1) 쪽으로 끌려간다**는 뜻이고(가중치가 양수), 빨간 칸은 **세모(0) 쪽으로 끌려간다**는 뜻이에요(가중치가 음수). 색이 진할수록 영향이 크고요.

이 그림이 또렷한 모서리·선 모양으로 보이면, 모델이 데이터에서 **세모와 네모를 가르는 진짜 시각적 단서**를 잡아냈다는 뜻이에요. 네모의 곧은 변이 있을 자리가 파랗게, 세모의 비스듬한 변 자리가 빨갛게 정렬되면 잘 학습된 모델입니다. 흐릿하거나 색이 뒤섞여 보이면 데이터가 더럽거나 학습이 부족하다는 신호일 수 있어요.
</details>

## 6. 다음으로

축하합니다. 이진 분류 모델 한 개를 처음부터 끝까지 학습시켰어요. 이제 여러분은 이런 흐름을 이해하고 있어요.

- 데이터를 정의한다 (입력·라벨·특징).
- 더러운 표본을 빼낸다 (전처리).
- 학습용/평가용으로 나눈다.
- 한 step 흐름으로 학습한다 (예측 → 오차 → 기울기 → 갱신).
- 시그모이드로 0~1 출력을 만들고 0.5로 가른다.
- 평가용 정확도와 가중치 시각화로 결과를 검증한다.

세모 vs 네모는 사실 단순한 문제예요. 다음 영역에서는 좀 더 어려운 문제로 갑니다 — **사람이 손으로 쓴 0~9 숫자 그림**을 분류하는 문제예요. 종류가 두 개에서 열 개로 늘어나고, 그림의 모양도 더 복잡해져요. 그 도전을 위해서는 모델 구조에 새 친구가 등장해야 해요.
