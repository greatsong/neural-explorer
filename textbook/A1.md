# A1. 인공 뉴런의 예측

> 인공 뉴런 한 개가 입력으로부터 어떻게 하나의 예측 숫자를 만드는지 — 그 한 줄짜리 계산을 끝까지 따라가요.

[A1을 앱에서 열기](https://neural-explorer-six.vercel.app/#/a1)

## 들어가며

이 책의 출발점이에요. 우리는 결국 "신경망이 어떻게 스스로 더 잘하게 되는가"를 보고 싶지만, 그러려면 먼저 "신경망이 한 번에 무슨 계산을 하는지"부터 손에 잡혀 있어야 해요. 그래서 A1에서는 학습은 잠시 잊고, **인공 뉴런 한 개가 한 번 계산을 끝낼 때 안에서 무슨 일이 일어나는지** 만 봅니다.

이번 챕터에서 답할 질문 하나만 머리에 두세요.

> **입력 숫자 두 개를 넣으면, 인공 뉴런은 어떤 절차로 하나의 예측 숫자를 만들어 낼까요?**

## 1. 핵심 아이디어

인공 뉴런 한 개가 하는 일은 한 줄로 줄일 수 있어요.

> **입력에 가중치를 곱해 모두 더하고, 편향을 보탠 다음, 활성화 함수를 한 번 통과시킨다.**

이 한 줄에 들어 있는 부품은 네 가지예요. 이름만 먼저 말해 둘게요. 곧 하나씩 풀어쓸 거예요.

- **입력**: 뉴런이 보고 판단할 숫자들이에요. 여기서는 두 개를 쓸게요. `x₁`, `x₂` 라고 부를게요.
- **가중치**: 입력마다 짝지어진 "이 입력을 얼마나 진지하게 들을지"의 정도예요. 입력이 두 개니까 가중치도 두 개예요. `w₁`, `w₂` 라고 부를게요.
- **편향**: 입력과 무관하게 뉴런이 가진 자기만의 한 숫자예요. `b` 라고 부를게요.
- **활성화 함수**: 위에서 만든 한 숫자를 마지막으로 한 번 더 다듬는 함수예요.

머리속 그림은 이래요. 두 개의 입력 동그라미가 왼쪽에 있고, 가운데에 큰 합산 동그라미가 있고, 오른쪽에 활성화 박스를 거쳐 마지막 출력 동그라미가 나와요. 입력에서 합산 동그라미로 가는 두 줄 위에 가중치가 적혀 있고, 합산 동그라미 머리 위에 편향이 작게 붙어 있어요. 이 그림이 사실상 "인공 뉴런 한 개"의 전부예요.

## 2. 차근차근

이 한 줄을 천천히 네 단계로 쪼개 볼게요.

### 1단계 — 입력에 가중치를 곱한다

뉴런 입장에서 입력 `x₁` 과 `x₂` 가 한 사건의 두 정보라고 생각해 보세요. 두 정보의 중요도가 똑같지 않을 수 있죠. 어떤 정보는 더 비중 있게 듣고, 어떤 건 살짝만 듣고 싶을 수 있어요. 그 비중이 가중치예요.

각 입력에 자기 가중치를 곱해요.

- 첫 번째: `w₁ · x₁`
- 두 번째: `w₂ · x₂`

가중치가 큰 양수면 그 입력의 영향을 크게 키우는 거고, 0에 가까우면 거의 무시하는 거고, 음수면 "이 입력이 클수록 결과를 깎는다"는 뜻이에요.

### 2단계 — 가중치 곱들을 모두 더한다

뉴런은 정보를 따로따로 두지 않고 하나의 숫자로 합쳐요. 1단계의 결과 두 개를 그냥 더해요.

$$
w_1 x_1 + w_2 x_2
$$

이 한 숫자가 뉴런이 "내 안에서 본 입력의 무게 합"이에요.

### 3단계 — 편향을 더한다

여기에 뉴런 자신의 숫자 `b` 를 더해요. 편향은 "입력이 뭐든 일단 이만큼은 깔고 들어간다"의 정도라고 생각하면 돼요. 입력이 모두 0이어도 편향 덕분에 뉴런은 0이 아닌 값을 만들 수 있어요.

여기까지 합친 결과를 한 글자로 `z` 라고 부를게요. 이 `z` 가 활성화 함수에 들어가기 직전의 숫자예요.

$$
z = w_1 x_1 + w_2 x_2 + b
$$

### 4단계 — 활성화 함수를 한 번 통과시킨다

`z` 를 마지막으로 한 번 더 다듬어 줄 함수가 활성화 함수예요. 이 책의 앱에서는 세 종류를 골라 볼 수 있어요. 셋 다 입력 한 숫자를 받아 출력 한 숫자를 돌려주는 함수예요.

- **linear** — 들어온 그대로 내보내요. `z` 가 그대로 나와요.
- **ReLU** — 음수면 0으로 깎아내고, 0 이상이면 그대로 통과시켜요. 가장 널리 쓰여요.
- **sigmoid** — 어떤 숫자가 들어오든 0과 1 사이의 값으로 부드럽게 짜내는 곡선이에요. 큰 양수는 1에 가까운 값으로, 큰 음수는 0에 가까운 값으로 눌려요.

활성화 함수의 출력이 인공 뉴런 한 개의 **최종 예측**이에요. 우리는 이 예측을 `ŷ` 이라고 적을게요. ŷ 의 모자(^)는 "예측한 값"이라는 뜻이에요. 곧 정답 `y` 와 짝을 맞춰야 하기 때문에, 정답과 헷갈리지 않게 모자를 씌워요.

### 한 줄로 다시

네 단계를 한 줄로 모으면 이래요.

$$
\hat{y} = \text{활성화}(w_1 x_1 + w_2 x_2 + b)
$$

머리속 그림으로 다시 한 번 — 입력 두 개 → 각각에 가중치를 곱 → 합 → 편향 더함 → 활성화 함수 통과 → 예측 한 숫자. 이게 이 책 끝까지 변하지 않아요. 우리가 앞으로 만질 모든 것은 결국 이 한 줄짜리 계산기를 더 잘 작동하게 만드는 일이에요.

### 가중치와 편향의 역할 차이

같은 부품이지만 역할이 좀 달라요.

- **가중치**는 "입력에 곱해지는" 숫자예요. 입력이 0이면 가중치가 아무리 커도 영향이 0이에요.
- **편향**은 입력에 곱해지지 않고 항상 더해지기만 해요. 입력이 0이어도 편향은 그대로 살아 있어요.

그래서 가중치는 입력에 따라 결과가 어떻게 휘어질지를 정하고, 편향은 결과 전체를 위아래로 옮기는 역할이에요.

## 3. 손으로 따라하기

부품을 손에 익히려면 한 번은 직접 계산해 보는 게 제일 빨라요. 다음 값을 받았다고 생각해 보세요.

> `x₁ = 2`, `x₂ = 3`, `w₁ = 1.5`, `w₂ = -1`, `b = 2`, 활성화 함수 = ReLU

순서대로 따라가요.

1. 가중치를 곱해요. `w₁ · x₁ = 1.5 × 2 = 3`. `w₂ · x₂ = (-1) × 3 = -3`.
2. 모두 더해요. `3 + (-3) = 0`.
3. 편향을 더해요. `0 + 2 = 2`. 이게 `z` 예요.
4. ReLU를 통과시켜요. `z = 2` 는 음수가 아니므로 그대로 나와요. `ŷ = 2`.

<details>
<summary>풀이 보기</summary>

`z = 1.5 × 2 + (-1) × 3 + 2 = 3 - 3 + 2 = 2`. ReLU(2) = 2. 따라서 ŷ = 2 입니다.

</details>

이번에는 같은 입력에 가중치만 살짝 바꿔 볼게요.

> `x₁ = 2`, `x₂ = 3`, `w₁ = -2`, `w₂ = 0.5`, `b = 1`, 활성화 함수 = ReLU

<details>
<summary>풀이 보기</summary>

`z = (-2) × 2 + 0.5 × 3 + 1 = -4 + 1.5 + 1 = -1.5`. ReLU는 음수를 0으로 깎으므로 ŷ = 0 입니다. 같은 입력이어도 가중치가 바뀌면 예측이 완전히 달라져요.

</details>

## 4. 앱에서 확인하기

[A1을 앱에서 열기](https://neural-explorer-six.vercel.app/#/a1)

A1 화면에는 왼쪽에 뉴런 다이어그램, 오른쪽에 슬라이더 다섯 개와 활성화 함수 토글이 있어요. 다음 순서대로 만져 보세요.

1. 일단 모든 값을 한 번 살펴봐요. 다이어그램 가운데 큰 Σ 동그라미를 거쳐 활성화 박스, 그리고 마지막 ŷ 동그라미가 보이죠. Σ 위에 편향, 두 줄 위에 가중치 라벨이 떠 있어요.
2. `x₁` 슬라이더를 -3에서 3까지 천천히 움직여 보세요. 다이어그램 왼쪽 동그라미의 숫자가 바뀌면서 가운데의 `z` 와 오른쪽의 ŷ 이 같이 변해요.
3. 다음으로 `w₁` 을 0으로 내려 보세요. 입력 `x₁` 을 아무리 움직여도 ŷ 이 거의 변하지 않을 거예요. 가중치가 0이면 그 입력은 사실상 무시된다는 뜻이에요.
4. 편향 `b` 슬라이더를 위아래로 움직여 보세요. 입력을 손대지 않아도 ŷ 이 위아래로 같이 따라 움직여요.
5. 활성화 함수를 ReLU → linear → sigmoid 순으로 바꿔 보면서 같은 `z` 가 어떻게 다른 ŷ 으로 변환되는지 보세요. linear는 그대로, ReLU는 음수를 0으로 깎고, sigmoid는 0과 1 사이로 부드럽게 짜내요.
6. 마지막으로 화면 아래 **미니 순전파 퀴즈**에서 직접 답을 입력해 정답 ŷ 을 맞혀 보세요. 위 "손으로 따라하기"의 첫 문제와 같은 값이에요.

여기서 두 가지를 확인하면 충분해요.

- 같은 입력이어도 가중치·편향을 바꾸면 예측이 완전히 달라진다.
- 가중치는 "곱하는 자리", 편향은 "더하는 자리"여서 영향 방식이 다르다.

## 5. 스스로 점검

**문제 1.** `x₁ = 1`, `x₂ = 2`, `w₁ = 2`, `w₂ = -1`, `b = 0`, 활성화 함수 = linear 일 때 ŷ 은 얼마인가요?

<details>
<summary>정답 보기</summary>

`z = 2 × 1 + (-1) × 2 + 0 = 0`. linear는 그대로 내보내므로 ŷ = 0 입니다.

</details>

**문제 2.** 위 문제에서 활성화 함수만 ReLU로 바꾸면 ŷ 은 어떻게 되나요? 음수가 들어오면 ReLU가 어떻게 처리하는지도 한 줄로 적어 보세요.

<details>
<summary>정답 보기</summary>

`z = 0` 이므로 ReLU(0) = 0. 즉 ŷ = 0 으로 변하지 않아요. ReLU는 음수가 들어오면 0으로 깎고, 0 이상이면 그대로 통과시키는 함수예요.

</details>

**문제 3.** 다음 중 **틀린** 설명을 고르세요.

- (가) 가중치가 0이면 그 입력은 결과에 거의 영향을 주지 않는다.
- (나) 편향은 입력에 곱해진 뒤에 더해진다.
- (다) `z` 는 활성화 함수를 통과하기 직전의 한 숫자다.
- (라) sigmoid는 큰 양수가 들어오면 1에 가까운 값을 돌려준다.

<details>
<summary>정답 보기</summary>

(나) 입니다. 편향은 입력에 곱해지지 않고, 가중치 곱들을 모두 더한 뒤에 한 번 더 더해지는 숫자예요.

</details>

**문제 4.** 가중치와 편향이 둘 다 0이고 활성화 함수가 linear 라고 합시다. 입력을 어떻게 바꿔도 ŷ 은 항상 어떤 값일까요? 그 이유를 한 줄로 적어 보세요.

<details>
<summary>정답 보기</summary>

ŷ = 0 입니다. 가중치가 모두 0이면 입력에 무엇이 곱해지든 결과가 0이고, 편향도 0이라 더할 게 없으니 `z = 0`. linear는 그대로 내보내므로 ŷ = 0 입니다.

</details>
